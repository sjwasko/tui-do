## The two things that will bite

**The README's install instructions have never been executed.** The repo is private, so the
release URL answers **404** to anyone unauthenticated, and `gh` is not installed on
`laptop`, `arm-host-1` or `arm-host-2` — so no host can authenticate either. The rc test
therefore ships the binary from `workstation` by `scp`, which proves the *artifact* and not the
*instructions*. Closing that is a step in Task 7 and it is easy to forget, because by then
everything will look finished.

**The version lives in four places in `Cargo.toml`** — `[workspace.package] version` at line
6, and the three internal path dependencies at lines 23–25, which carry literal versions
only because `cargo-deny`'s `wildcards = "deny"` rejects a versionless path dependency. Miss
the three and the failure arrives much later as a `cargo-deny` error. The obvious `sed`
one-liner using `|` as both delimiter and alternation **silently bumps only line 6 and exits
0** — verified on 2026-09-06. Use line-addressed substitution.

## The release pipeline

`.github/workflows/release.yml`, on a `v*` tag: `gate` → `licenses` → `build` (x86_64 and
aarch64) → `publish`. A tag containing a hyphen publishes as a pre-release.

**Three things in it look odd and are deliberate. Do not tidy them.**

- **The static check greps twice** — rejecting `dynamically linked`, accepting either
  `static-pie linked` *or* plain `statically linked`. aarch64 comes out non-PIE while x86_64
  is PIE, so a check demanding `static-pie` would fail every arm release forever.
- **`cargo install cargo-about --version 0.9.2 --locked --features=cli`.** cargo-about has no
  default feature; without `--features=cli` it installs **no binary at all**.
- **`sha256sum` runs inside `dist/`** while the release glob reads `dist/*.tar.gz` from the
  repo root. That is load-bearing: `SHA256SUMS` must carry bare filenames for the README's
  `sha256sum --check` to work.

`THIRD-PARTY-LICENSES.md` is generated at release time and gitignored — a static binary
redistributes ~400 crates, and every licence `deny.toml` admits requires attribution.
